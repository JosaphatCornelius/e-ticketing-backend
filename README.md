# E-Ticketing-Backend

Build Status: Deployed

The backend that connects to the frontend that I made back in senior high school. There's many things to improve in this backend.

## Tech Stack

- **Core:** [ASP .NET Core]
- **Database:** [PostgreSQL, Entity Framework Core]
- **Infrastructure:** [Docker]

## Quick Start

Instructions to get the development environment running locally.

```
# Clone the repository
git clone https://github.com/JosaphatCornelius/e-ticketing-backend.git
cd e-ticketing-backend

# Install dependencies and run
dotnet run
```

## Usage

```
dotnet run
```
